# CS Career & Internship Guide

## Internship Application Timeline

### Summer 2026 Internships
- **August–September 2025:** Large tech (Google, Meta, Amazon, Microsoft) open applications. Apply immediately.
- **October–November 2025:** Mid-size tech, fintech, startups open.
- **January–March 2026:** Last wave — many companies still hiring. Don't give up.
- **Tip:** Apply to 40–60 companies minimum. The acceptance rate at top companies is under 5%.

## Resume Tips
- Keep to 1 page until you have 10+ years of experience.
- Lead bullet points with strong action verbs: Designed, Implemented, Reduced, Increased.
- Quantify impact: "Reduced API latency by 40%" beats "Improved API performance."
- Skills section: List languages you can code in during an interview, not languages you've touched once.
- GPA: Include if 3.5+. Optional otherwise.
- ACSU resume review: Available every fall. Check the calendar for workshop dates.

## Technical Interview Prep
- **LeetCode:** Focus on mediums. Arrays, strings, trees, graphs, DP are most common.
- **System design:** For junior roles, know how to design a URL shortener, chat app, or news feed at a high level.
- **Behavioral:** Prepare 5 STAR stories covering teamwork, conflict, failure, and achievement.
- **Practice resources:** LeetCode, NeetCode.io, Interviewing.io, CTCI (Cracking the Coding Interview).

## Salary Expectations (2025 Data)
- FAANG SWE intern: $8,000–$12,000/month + housing
- Mid-size tech: $5,000–$8,000/month
- Startup: $4,000–$7,000/month (equity sometimes offered)
- Finance/quant: $10,000–$15,000/month
