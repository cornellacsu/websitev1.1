# CS Course Wiki

## CS 2110 — Object-Oriented Programming & Data Structures
- **Credits:** 4
- **Prerequisites:** CS 1110 or equivalent
- **Topics:** Java, OOP, recursion, linked lists, trees, graphs, sorting, Big-O
- **Exams:** 2 prelims + final. Past exams on course website.
- **Office Hours:** MWF 1–4 PM, Rhodes Hall 471. Also on CMS.
- **Tips:** Start projects 4–5 days early. The JavaFX GUI project is time-consuming.

## CS 3110 — Functional Programming & Data Structures
- **Credits:** 4
- **Prerequisites:** CS 2110
- **Topics:** OCaml, functional programming, type systems, formal verification, modules
- **Exams:** 2 prelims, no final (replaced by project). Past prelims on course wiki.
- **Office Hours:** Daily 2–5 PM, Gates Hall 216.
- **Tips:** Read documentation. Type errors are your friend. Start A2 (RBT) two weeks early.

## CS 4780 — Introduction to Machine Learning
- **Credits:** 4
- **Prerequisites:** CS 2800, MATH 2940, probability course
- **Topics:** Linear regression, SVM, decision trees, neural networks, PAC learning
- **Exams:** 2 prelims. Heavy math. Derivations on exams.
- **Office Hours:** TuTh 3–6 PM, Gates Hall 406.
- **Past Exams:** Available on course website under "Resources."

## CS 4820 — Introduction to Analysis of Algorithms
- **Credits:** 4
- **Prerequisites:** CS 2110, CS 2800
- **Topics:** Greedy, divide-and-conquer, DP, network flow, NP-completeness, approximation
- **Exams:** 3 prelims + final. Proof-heavy.
- **Office Hours:** MWF 2–4 PM, Upson Hall 315.
- **Tips:** Form study groups for homework. Proofs are graded on rigor, not just correctness.

## CS 3410 — Computer System Organization
- **Credits:** 4
- **Prerequisites:** CS 2110
- **Topics:** MIPS assembly, pipelining, caching, virtual memory, I/O
- **Labs:** Weekly labs in Gates Hall B-level lab rooms (B11, B13).
- **Office Hours:** Mon–Thu 6–9 PM, ACCEL lab.

## Adding/Dropping Courses
- Add/drop deadline: typically the end of week 2.
- S/U option deadline: week 6.
- Check the registrar's academic calendar for exact dates each semester.
